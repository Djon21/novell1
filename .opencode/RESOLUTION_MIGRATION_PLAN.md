# План миграции разрешения: 960×640 → 1280×720

**Дата:** 2026-04-20  
**Проект:** AVOS (все варианты: C, G, M, Q, S)  
**Цель:** Переход на стандартное разрешение 16:9 для лучшей совместимости с Яндекс.Играми

---

## 📊 Анализ изменений

### Коэффициенты масштабирования:
- **Ширина:** 1280 / 960 = **1.333× (×4/3)**
- **Высота:** 720 / 640 = **1.125× (×9/8)**
- **Соотношение сторон:** 3:2 → 16:9 (более широкий экран)

### Масштаб изменений:
- **~150+ файлов** требуют обновления
- **5 вариантов AVOS** (C, G, M, Q, S) - изменения идентичны
- **Работаем только в AVOS_S**, затем мержим в остальные

---

## 🎯 Стратегия миграции

### Вариант A: Полная миграция (рекомендуется)
**Плюсы:**
- Стандартное разрешение 16:9
- Лучше для современных экранов
- Больше места для UI элементов

**Минусы:**
- Требует пересоздания всех фонов (1280×720)
- Нужно пересчитать все координаты
- Большой объём работы (~150 файлов)

### Вариант B: Letterboxing (быстрое решение)
**Плюсы:**
- Минимальные изменения кода
- Фоны остаются 960×640
- Быстрая реализация

**Минусы:**
- Чёрные полосы по бокам
- Не использует весь экран
- Менее профессионально

### Вариант C: Адаптивный UI
**Плюсы:**
- Работает на любом разрешении
- Максимальная гибкость

**Минусы:**
- Самая сложная реализация
- Требует переработки всей системы

## 🔧 Инструменты и скрипты

### Скрипт для пересчёта координат
```lua
-- tools/scale_coordinates.lua
local SCALE_X = 1.333
local SCALE_Y = 1.125

local function scale_position(x, y)
    return math.floor(x * SCALE_X), math.floor(y * SCALE_Y)
end

local function scale_size(w, h)
    return math.floor(w * SCALE_X), math.floor(h * SCALE_Y)
end

local function scale_rect(rect)
    return {
        x = math.floor(rect.x * SCALE_X),
        y = math.floor(rect.y * SCALE_Y),
        w = math.floor(rect.w * SCALE_X),
        h = math.floor(rect.h * SCALE_Y)
    }
end

-- Использование:
-- local new_x, new_y = scale_position(480, 320)
-- print(new_x, new_y)  -- 640, 360
```

### Скрипт для массового обновления .gui файлов
```python
# tools/update_gui_resolution.py
import re
import os

def update_gui_file(filepath):
    with open(filepath, 'r', encoding='utf-8') as f:
        content = f.read()
    
    # Replace 960.0 with 1280.0
    content = re.sub(r'x: 960\.0', 'x: 1280.0', content)
```
