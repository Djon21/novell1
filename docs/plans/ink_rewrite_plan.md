### 2.1 `bar_sunday.ink` — разговор про кейс 017
**Строки 117-141** — ключевой момент, где MC объясняет NPC про систему.
Сейчас:
```
— Система сказала: данных недостаточно. И сама применила стандартное решение.
  Я даже не успел ничего выбрать — таймер вышел, и кейс закрылся.
— Это AVOS. Если система применила решение без твоего подтверждения —

```
Должно стать (свободный пересказ, точный текст — при чистовике):
```
— Система не стала ждать. Просто закрыла задачу сама. Я даже открыть её не успел.
— Я знаю. AVOS так работает. Не спросила — значит, в логах будет ровная запись.
```

- Убрать «стандартное решение» из реплик
- «таймер вышел» → «я не успел / время вышло»

## Этап 3 — Unknown (AVOS-глюк)

Полностью переписать `msg_thread_unknown` (`93_phone_messenger.ink:591-623`).

**Сейчас:** таинственный собеседник, даёт советы («Не соглашайся сразу»),
есть выбор «Кто это?», «Что соединить?».

**Должно стать:** AVOS-глюк. В чате появляются обрывки внутренних сообщений
системы. Никто их не писал — это сбой вывода.

Новый текст (набросок):
```
=== msg_thread_unknown ===
# speaker:none
В чате без имени — обрывки логов. 
Будто система зачем-то вывела их сюда.

[Статус: Кейс 017 — Ожидает]
[Статус: Кейс 017 — Просрочено]
[Статус: Кейс 017 — Закрыто автоматом]
[Код операции: 017. Статус: финальный.]

{iteration_number > 1:
Эта строка появлялась и в прошлый раз.
}

* [Прочитать ещё раз]
    Ничего не меняется. Это просто логи.
    # return_to_scene
    -> DONE

* [Закрыть чат]
    # return_to_scene
    -> DONE
```

Убрать:
- опции «Кто это?», «Что соединить?»
- начисление `SYNC`
- совет «Не соглашайся сразу. Сначала спроси»
