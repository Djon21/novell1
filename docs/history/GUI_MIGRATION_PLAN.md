- Один файл novel_ui.gui содержит ВСЁ: меню, диалоги, инвентарь, телефон, hotspots, портреты
- Один скрипт novel_ui.gui_script (1670 строк) управляет всем

**Целевое состояние:**
- 6 отдельных GUI компонентов
- GUI templates для повторяющихся элементов
- Lua модули для общей логики
- ui_manager для координации

**Общее время выполнения:** 4-6 недель
