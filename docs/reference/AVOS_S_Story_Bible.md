
# AVOS_S — STORY BIBLE (FINAL v10)

---

# 1. OVERVIEW
Narrative loop game про интерпретацию, повторение и принятие решений при неполной информации.

---

# 2. AUTHOR TRUTH (НЕ ВИДНО ИГРОКУ)
В будущем система ИИ начинает принимать решения за людей.

Причина:
"если данных недостаточно — система решает сама"

Будущий ГГ:
- осознаёт ошибку
- создаёт временную петлю
- отправляет искажённые сообщения в прошлое

Ограничения:
- нельзя передать прямой ответ
- информация искажается
- контроль частичный

---

# 3. IN-GAME TRUTH
Игрок видит:
- повтор 3 дней
- аномалии
- déjà vu
- несостыковки

Игрок НЕ знает источник.

---

# 4. CORE LOOP
ИНФОРМАЦИЯ → ИНТЕРПРЕТАЦИЯ → ВЫБОР → ПОСЛЕДСТВИЕ

---

# 5. LOOP SYSTEM

## Итерации
Бесконечные (001 → 002 → ...)

Каждая:
- 3 дня
- концовка
- возврат в меню

---

## Narrative Stages
Всего 5.
Прогресс не зависит от номера итерации.

---

# 6. GLOBAL PROGRESSION MODEL

Каждый Stage включает:

1. NPC Path → False Ending 1
2. System Path → False Ending 2
3. Synthesis Path → True Ending

True Ending открывается только после двух ложных.

После True:
- возврат в начало
- открытие следующего Stage
- сохранение понимания

---

# 7. 3-DAY STRUCTURE

Воскресенье — отношения
Понедельник — работа
Вторник — последствия

---

# 8. WORK ERROR SCENE (FINAL)

Ранние итерации:
- полностью автоматическая сцена
- игрок не участвует

Система:
“Данных недостаточно.”
(пауза)
“Применяется стандартное решение.”

Решение применяется автоматически.

---

Позже:
- появляется возможность вмешательства:
  - согласиться
  - спросить
  - отказаться

Ошибка = отсутствие сомнения.

---

# 9. PARAMETERS

TRUST — отношения с NPC → открывает NPC Path
INSIGHT — понимание системы → открывает System Path
ACTION — осознанное действие → нужен для True Ending

---

# 10. ENDINGS SYSTEM (FINAL)

Каждая итерация заканчивается концовкой.

Типы концовок:

False 1 (NPC Path):
- фокус на отношениях
- чувство близости
- недостаток понимания системы

False 2 (System Path):
- логическое решение
- недостаток контекста и поведения

True (Synthesis):
- объединение понимания
- отказ от автоматического решения

---

# 11. POST-ITERATION SYSTEM

После каждой концовки:

1. Игрок возвращается в меню
2. Увеличивается номер итерации
3. В журнале фиксируется прогресс

---

## Записи в журнале

После False 1:
“Я лучше понял её.
Но этого недостаточно.”

После False 2:
“Я попытался разобраться.
Но что-то не сходится.”

После True:
“Это связано.
Я не должен просто применять это.”

---

Правило:
Записи не дают инструкций, только направляют.

---
