# ROADMAP

Актуально на `2026-06-02`. Структура: 2 петли (пролог + финал).

## Ближайший Этап

- пройти smoke по полному маршруту обеих петель
- проверить `Continue` после новой структуры Ink
- проверить переход Петля 1 → Петля 2 (loop1_to_iter2_reset)
- проверить все 3 ending'а петли 2 (NPC / System / True)
- проверить эпилог и `game_completed` флаг

## Контент

- расширять loop-aware реплики через `iteration_number`, `loop_awareness`, `false_endings_count`
- наполнять телефон SMS, mail, calls, clues и terminal через Ink-теги
- добавлять новые предметные реакции через `91_inventory_actions.ink`

## UI

- телефон: проверить читаемость всех приложений на разных разрешениях
- карта: довести визуальные состояния пинов и выбранного маршрута
- меню: показать статус "Игра пройдена" при `game_completed = true`
- achievements: реализовать отдельным этапом или оставить скрытыми

## Техника

- сохранить однофайловый runtime `chapter_01.json`
- не возвращать legacy GUI как fallback
- перед релизом пройти `TESTING_CHECKLIST.md`
- проверить Яндекс SDK в собранной версии
