# АВОСЬ — Pre-release Testing Checklist

Актуально на `2026-04-25`. Проходить перед каждым публичным билдом.

---

## 1. Старт и меню

- [ ] Главное меню открывается, анимация логотипа работает (glitch, skyline)
- [ ] Отображается правильный номер итерации (`НАЧАТЬ ИТЕРАЦИЮ 001` при первом запуске)
- [ ] Кнопка «ПРОДОЛЖИТЬ» недоступна (серая) при отсутствии сохранения
- [ ] Кнопка «СБРОСИТЬ ИТЕРАЦИЮ» сбрасывает meta_state и возвращает в меню с iter 001
- [ ] «НОВАЯ ИТЕРАЦИЯ» запускает игру с чистым run-state

---

## 2. Диалог и Ink

- [ ] Текст печатается с typewriter-эффектом
- [ ] Клик по dbox / кнопка NEXT переходит к следующей реплике
- [ ] AUTO-режим автоматически продвигает диалог
- [ ] SKIP-режим пролистывает реплики без задержки
- [ ] Портрет и имя говорящего соответствуют `# speaker:`
- [ ] `# bg:` меняет фон
- [ ] `# sfx:` воспроизводит звук (coffee_brew, terminal_wake, phone_notify, heartbeat, paper_rustle)
- [ ] Выбор отображается корректно, нажатие фиксирует вариант
- [ ] Гендерные токены `{mc_gender == "female":...|...}` подставляются верно после выбора персонажа

---

## 3. Exploration (point-and-click)

- [ ] Фон сцены загружается без артефактов
- [ ] Hotspot'ы кликабельны, tooltip/label отображается
- [ ] `condition = false` блокирует hotspot (виден, но не активен)
- [ ] `visible_when = false` полностью скрывает hotspot
- [ ] Scene objects появляются и скрываются по флагам
- [ ] Переход между сценами через hotspot работает (apartment_hub ↔ kitchen ↔ bathroom ↔ bedroom)
- [ ] `ink_knot` hotspot запускает монолог и возвращает через `# return_to_scene`
- [ ] F1-редактор открывается и не ломает игровой процесс

---

## 4. Телефон

- [ ] Телефон открывается из HUD и закрывается кнопкой ✕
- [ ] Недоступен пока в инвентаре нет предмета `phone`
- [ ] SMS-вкладка: входящие сообщения отображаются в правильном порядке
- [ ] Квесты-вкладка: активные квесты видны, выполненные обновляются
- [ ] Mail, Calls, Clues-вкладки: данные, добавленные через ink-теги, появляются
- [ ] Camera-вкладка: статус и лейбл обновляются через `# camera:*`
- [ ] Terminal-вкладка: строки из `# term:*` добавляются с нужным цветом (ok/warn/err)
- [ ] Кнопка «Карта» в телефоне открывает приложение карты внутри телефона
- [ ] Переключение между вкладками не оставляет включённых нод от предыдущей

---

## 5. Карта

- [ ] `# phone:map` открывает телефон сразу на приложении карты
- [ ] Пины отображаются, hover-состояние работает
- [ ] Выбор POI в `phone_map` закрывает телефон и открывает нужный hub
- [ ] Отмена подтверждения POI оставляет игрока на карте телефона
- [ ] Карта не выбрасывает в главное меню при закрытии телефона

---

## 6. Инвентарь

- [ ] Инвентарь открывается из HUD
- [ ] Предмет добавляется через `# item:add:id` и отображается в слоте
- [ ] Verb (use/inspect/read) запускает нужный ink-knot
- [ ] Предмет удаляется через `# item:remove:id`
- [ ] При пустом инвентаре иконка HUD показывает 0

---

## 7. Loop-система и концовки

- [ ] Итерация 001: проходится линейно, `chapter_finished` → итерация 002, awareness = 0
- [ ] Ложная концовка `ending_npc` (`# loop:end:false:ending_npc`): run сбрасывается, та же итерация, awareness +1
- [ ] Ложная концовка `ending_system` (`# loop:end:false:ending_system`): аналогично, awareness +1
- [ ] Ложная концовка `ending_insight` (`# loop:end:false:ending_insight`): аналогично, awareness +1
- [ ] После 2 разных ложных концовок: в меню показывается та же итерация, awareness = 2
- [ ] Истинная концовка (`# loop:end:true`) недоступна при `false_endings_count < 2` (роутинг в Ink)
- [ ] Истинная концовка при `false_endings_count >= 2`: итерация +1, `false_endings_seen` сброшен, awareness сохранён
- [ ] Loop-aware реплики меняются при `loop_awareness > 0` (wake_intro, rooftop_entry, office_day_end и др.)
- [ ] При `loop_awareness >= 2` в `rooftop_conversation` доступен выбор «Я уже был здесь»

---

## 8. Save / Load

- [ ] Прогресс сохраняется автоматически на каждом шаге диалога
- [ ] «ПРОДОЛЖИТЬ» восстанавливает сцену, флаги и инвентарь
- [ ] После загрузки ink-история воспроизводится с `suppress_effects=true` — флаги и инвентарь не дублируются
- [ ] Exploration-сцена восстанавливается корректно (hotspot'ы в нужном состоянии)
- [ ] Side-dialogue (ink_knot из hotspot) → save → load → `# return_to_scene` возвращает в сцену
- [ ] meta_state (iteration_number, loop_awareness, false_endings_seen) переживает перезапуск игры
- [ ] «СБРОСИТЬ ИТЕРАЦИЮ» полностью сбрасывает и meta_state, и run-state

---

## 9. Звук и музыка

- [ ] Фоновая музыка запускается при первом нажатии
- [ ] SFX-эффекты из диалога воспроизводятся (не крашатся при отсутствующем файле)
- [ ] Повторный запуск музыки не создаёт наложения треков

---

## 10. Яндекс SDK (только в браузерном билде)

- [ ] Игра запускается в iframe Яндекс Игр без ошибок в консоли
- [ ] Сохранения работают через Яндекс SDK (если подключён cloud save)
- [ ] Реклама (если подключена) не ломает game loop
- [ ] Достижения фиксируются (если реализованы)
- [ ] Игра корректно реагирует на `ysdk.features.LoadingAPI.ready()`

---

## 11. Производительность и стабильность

- [ ] Нет утечек таймеров: glitch-таймер меню останавливается при `hide_menu`
- [ ] Переключение между меню → игрой → меню несколько раз подряд не деградирует
- [ ] Несколько последовательных итераций (3+) без перезапуска движка работают стабильно
- [ ] Консоль не содержит spam-принтов в релизном режиме: `log.set_level("warn")` обрезает info/debug/trace (см. `docs/guides/LOGGING.md`)
- [ ] Нет ошибок `attempt to index nil` в логах при нормальном прохождении

---

## Быстрый smoke-тест (5 минут)

Минимальный набор для проверки после каждого коммита:

1. Запустить → меню появилось, логотип глитчует
2. «НОВАЯ ИТЕРАЦИЯ» → wake_intro → выбрать персонажа → добраться до apartment_hub
3. Взять кружку → сварить кофе → взять телефон → открыть телефон → SMS видны → закрыть
4. Выйти из квартиры → карта → метро → офис → крыша → любая концовка → меню
5. «ПРОДОЛЖИТЬ» → оказаться там же где остановились (или в начале итерации после концовки)
