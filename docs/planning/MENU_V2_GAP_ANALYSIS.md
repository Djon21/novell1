## Ключевые различия

## 1) Фон и атмосфера (самый большой разрыв)

- В HTML: многослойная сцена (звездная пыль, sky glow, 2 skyline SVG слоя, haze, rain canvas, desk, monitor, keyboard, cup+steam, grain, vignette, CRT lines).
- В игре: плоский фон + 3 простых динамических прямоугольника skyline.

Влияние: визуально меню в игре ощущается «черновым» относительно референса.

## 2) Структура меню-кнопок

- В HTML: большие интерактивные кнопки-плашки с индексом, RU+EN подписями, стрелкой, hover-состоянием, disabled-стилем.
- В игре: текстовые строки без контейнеров, без стрелок, без подподписей, без disabled-варианта.

Влияние: слабее UX и «неон-досье» стиль.

## 3) Логотип и branding-детали

- В HTML: split-glitch через clip-path на верх/низ, вспомогательные линии вокруг eyebrow.
- В игре: только смещенные текстовые слои и jitter по X, без split-эффекта.

Влияние: логотип менее выразителен.

## 4) Штамп

- В HTML: повернутый, рамка 2px, шум/текстура, screen/multiply эффекты.
- В игре: обычный текст-штамп без печатной фактуры и rotation.

## 5) Досье-панель

- В HTML: card с угловыми маркерами, live-бейдж, строки-поля, scene-thumb, progress bar + label, tip/caveat.
- В игре: упрощенный блок с заголовком, прогрессом и описанием, без scene-thumb/progress bar/live.

## 6) HUD-полосы в меню

- В HTML: верхняя и нижняя HUD-плашки видимы в menu state.
- В игре: меню-компонент не повторяет этот слой как в макете.

## 7) Микроанимации и переходы

- В HTML: stagger fade-up, blinking lights, twinkle, steam, boot overlay при Start.
- В игре: базовые анимации есть (ticker/glitch/parallax), но нет boot overlay и части атмосферных циклов.

## 8) Адаптивность меню

- В HTML: responsive правила (`@media`, скрытие dossier при малой ширине).
- В игре: фиксированная компоновка Defold без отдельного mobile-layout для menu.

## 9) Технический долг после миграции резолюции

- В `main_menu_v2.gui_script` skyline слой создается с шириной `960` (жестко), хотя проект уже `1280x720`.

Влияние: потенциальный визуальный mismatch на краях.

## Риски и ограничения (Defold)

- Не использовать `gui.set_parent()` для динамических новых нод меню (риск невидимого рендера).
- Явно выставлять `z` для динамики, чтобы не уйти под фон.
- Следить за alpha inheritance у root-контейнеров (`color.w = 1.0`).
- Не ломать порядок GUI-компонентов в `main/main_v2.collection`.
