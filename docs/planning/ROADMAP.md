# АВОСЬ — Roadmap

Статус документа: Active
Последняя синхронизация с кодом: 2026-04-21

Игра эволюционирует из «визуальной новеллы с выборами» в **point-and-click adventure с RPG-элементами**: свободная навигация по комнатам/карте, инвентарь, квесты в телефоне, интерактивные hotspot-зоны. Ink остаётся как подсистема для диалогов/монологов, но перестаёт быть драйвером игры.

Целевая платформа — **Яндекс.Игры в браузере, ПК + мобильные**. Все интерактивные элементы должны быть достаточно крупными и визуально подсвеченными для тапа пальцем на мобильном.

---

## Решения по архитектуре

- **Game State Layer (Lua)** — единственный источник правды: inventory, quests, flags, current_scene.
- **Scene Graph (Lua)** — комнаты/локации как данные: bg + hotspot'ы + условия + on_click.
- **HUD** — всегда поверх сцены: иконки инвентаря / телефона / карты в правом верхнем углу.
- **Модалки** — инвентарь, телефон, карта открываются поверх сцены по клику на HUD-иконку.
- **Ink** — вызывается сценой для диалогов (`ink.play_knot("talk_to_mila")`). Тэги ink могут изменять game_state (`# flag:has_coffee=true`, `# item:add:keys`).
- **Инвентарь — взаимодействие Verb Coin (SCUMM-style):** клик на hotspot → появляется радиальное мини-меню «взять / посмотреть / использовать с…». Мобильно-дружественно.
- **Hotspot'ы — всегда видимые** (подсветка/пульсация/иконка), потому что игра в браузере на мобилках. Невидимые зоны не годятся.
- **Сохранения** — единое сохранение game_state + ink-state вместе, ещё в фундаменте (Спринт 1).

## Спринт 1 — Фундамент (базовая инфраструктура)

Цель: заложить game_state + scene_controller без ломания текущей игры. Спальня, квартира, метро, офис, крыша продолжают работать.

- [x] `game_state.lua` — модуль с inventory/quests/flags/current_scene
- [x] Единое сохранение: `game_state` + ink-state в одном save-файле
- [x] `scene_controller.lua` — движок сцен: рендер фона, обработка кликов по hotspot'ам
- [x] `scenes.lua` — каталог сцен (данные), стартовая сцена `apartment_hub`
- [x] Ink-тег `# explore:scene_id` — передаёт управление scene_controller'у
- [x] Ink-тег `# flag:name=value`, `# item:add:id`, `# goto_scene:id`
- [x] Переделать текущий `apartment_hub` в ink под новый формат (минимальный — 3 перехода)
- [x] Инструмент отладки hotspot'ов реализован через F1-редактор

## Спринт 2 — Комнаты квартиры + интерактив

Цель: свободное хождение по квартире с pickup'ами и условиями выхода.

- [x] Сцена `kitchen` (`bg_kitchen`) с hotspot'ами: кофеварка, стол, выход в коридор
- [x] Сцена `bathroom` (`bg_bathroom`) с hotspot'ами: раковина, телефон-полочка, выход в коридор
- [x] Сцена `bedroom_day` (использует `bg_bedroom`) для возврата в спальню
- [x] Pickup-механика: hotspot с `action.type = add_item` добавляет предмет в инвентарь
- [x] Условие выхода из квартиры: `flags.has_coffee and inv.has("phone")` — разблокирует hotspot двери
- [x] Hotspot disabled-состояние (визуально тусклый) если условие не выполнено

## Спринт 3 — HUD + инвентарь

Цель: видимый инвентарь с иконкой в углу, открывается, предметы применимы.

- [x] `hud_v2.gui` — иконки инвентаря/телефона, статусы, локация
- [x] Скрытие HUD в нерелевантных режимах реализовано через `ui_manager_v2`
- [x] `inventory_v2.gui` — сетка слотов и details-панель
- [x] Иконки/описания предметов через `items_catalog.lua`
- [ ] Verb Coin: клик на hotspot → радиальное меню над hotspot'ом
  - Вариант жестов: короткий тап = «взять/действие по умолчанию», долгий тап = verb coin
- [ ] «Использовать предмет с …» — клик «использовать» в инвентаре → предмет становится курсором → клик по hotspot применяет

## Спринт 4 — Телефон + квесты

Цель: телефон с живым журналом квестов.

- [x] `phone_v2.gui` — стилизация под смартфон + app-вьюхи
- [x] `quests.lua` — каталог квестов: title, steps (предикаты над game_state)
- [x] Квест «Утро»: выпить кофе + взять телефон → разблокирует выход
- [x] Реактивное обновление: шаги квеста проверяются при каждом изменении game_state
- [ ] Уведомления: «квест обновлён» / «квест завершён» — всплывашка в углу + звук
- [ ] Опционально: SMS/сообщения внутри телефона как ink-сценарии

## Спринт 5 — Глобальная карта

Цель: выйти из квартиры → карта города → свободный переход в метро/офис/крышу.

- [x] `bg_city_map` — фон-карта добавлен
- [ ] Сцена `world_map` — hotspot'ы локаций: метро, офис, крыша, (и новые позже)
- [ ] Переход «выйти из подъезда» → `world_map`
- [ ] Сами локации (метро/офис/крыша) адаптируются: текущий ink остаётся, но вход и выход через сцену-контейнер
- [ ] Прогресс локаций: пройденная локация помечена на карте (изменённый hotspot, метка)
- [ ] Условия доступа локаций (по квестам): например, офис заблокирован пока не позвонили

## Принципы разработки

1. **Мобильный first** — все кликабельные зоны ≥ 48×48 dp, явная визуальная подсветка.
2. **Не ломать то что работает** — каждый спринт должен оставлять игру играбельной.
3. **Данные а не код** — комнаты/предметы/квесты как таблицы, а не захардкоженные ветки.
4. **Ink остаётся** — для всего что про текст/выборы/повествование. Просто перестаёт рулить сценами.
