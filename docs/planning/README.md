# Planning docs

Документы оперативного и стратегического планирования.

- `TODO.md` — живой оперативный список задач.
- `ROADMAP.md` — стратегические спринты и направления.
- `YANDEX_GAMES_REQUIREMENTS.md` — чеклист соответствия требованиям платформы.
- `MENU_V2_GAP_ANALYSIS.md` — разница между menu референсом и текущим in-game меню + план доработки.

Правило:

- `TODO.md` обновляется по факту выполненных работ.
- `ROADMAP.md` обновляется при изменении стратегии или статуса крупных блоков.
