## 🚀 ПЛАН ДЕЙСТВИЙ

### Этап 1: SDK и техническая интеграция (2-3 часа)
1. Проверить инициализацию defold-yagames SDK
2. Добавить LoadingAPI.ready()
3. Реализовать остановку звука при сворачивании
4. Добавить автоопределение языка

### Этап 2: Реклама (1-2 часа)
1. Подключить РСЯ
2. Настроить показ рекламы в логических паузах
3. Протестировать rewarded video (если планируется)

### Этап 3: Промоматериалы (2-3 часа)
1. Создать иконку 512×512
2. Создать обложку 1280×720
3. Сделать 3-5 скриншотов геймплея
4. Написать описание игры

### Этап 4: Тестирование (3-4 часа)
1. Тестирование на десктопе (Chrome, Firefox, Яндекс.Браузер)
2. Тестирование на мобильных (Android, iOS)
3. Проверка всех требований из чеклиста
4. Исправление найденных багов

### Этап 5: Публикация (1 час)
1. Заполнение черновика в Консоли
2. Загрузка архива игры
3. Отправка на модерацию
