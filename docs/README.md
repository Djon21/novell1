# Документация AVOS_S

Документы проекта разложены по папкам, чтобы активные инструкции не смешивались с legacy-архивом.

## Структура

- `reference/` — опорные документы по текущему проекту
- `guides/` — практические how-to и рабочие инструкции
- `archive/legacy-ui/` — исторические материалы по старому UI и миграции
