# Документация проекта

Единая точка входа для всех документов AVOS.

## Структура

- `guides/` — рабочие инструкции (как добавить сцену, фон, звук и т.д.).
- `planning/` — живые документы планирования и релизной готовности.
- `history/` — исторические отчёты миграций и разовых инициатив (архив).
- `internal/` — внутренние технические заметки и инженерные практики.

## Что читать в первую очередь

- `../README.md` — общее описание проекта.
- `planning/TODO.md` — актуальные задачи на ближайший спринт.
- `planning/ROADMAP.md` — стратегический план развития.
- `planning/YANDEX_GAMES_REQUIREMENTS.md` — чеклист публикации в Яндекс.Играх.
- `guides/HOW_TO_ADD_SCENES.md` — основной рабочий гайд для контентной разработки.

## Статус категорий

- **Active:** `guides/`, `planning/`.
- **Reference/Internal:** `internal/`.
- **Archive:** `history/` (не использовать как источник текущей архитектуры без перепроверки).

## Правила поддержания порядка

1. Новый практический гайд кладём в `guides/`.
2. План/чеклист — в `planning/`.
3. Разовый отчёт по миграции/эксперименту после завершения переносим в `history/`.
4. Если документ устарел, в начале файла добавляем пометку `Статус: Archive`.
5. В `../README.md` держим ссылки только на актуальные документы из `guides/` и `planning/`.
