# Инструкция по добавлению портретов персонажей

## Что такое портрет?

**Портрет** — это изображение персонажа, которое показывается слева от диалоговой панели во время разговора. Портреты автоматически появляются когда персонаж говорит.

---

## Требования к портретам

- **Разрешение:** 512×512 пикселей
- **Формат:** PNG (.png)
- **Прозрачность:** Обязательна (прозрачный фон)
- **Цветовое пространство:** RGBA
- **Стиль:** Портрет персонажа по пояс/грудь
- **Размер файла:** ~200-300 KB

---

## Шаг 1: Подготовка изображения

1. Создайте портрет персонажа **512×512 px**
2. Убедитесь что фон **прозрачный** (альфа-канал)
3. Персонаж должен быть по центру
4. Сохраните в формате **PNG**
5. Назовите файл по имени персонажа: `имя.png` (латиница, lowercase)

**Примеры:**
- `artem.png` - портрет Артёма
- `mila.png` - портрет Милы
- `anya.png` - портрет Ани

---

## Шаг 2: Добавление файла в проект

1. Поместите файл в папку: `main/images/`
2. Пример: `main/images/anya.png`

---

## Шаг 3: Регистрация в атласе

1. Откройте файл: `main/images/characters.atlas`
2. Добавьте новую запись **перед** строками `margin: 0`:

```
images {
  image: "/main/images/имя.png"
}
```

**Пример для Ани:**
```
images {
  image: "/main/images/anya.png"
}
```

**Полный пример characters.atlas:**
```
images {
  image: "/main/images/artem.png"
}
images {
  image: "/main/images/mila.png"
}
images {
  image: "/main/images/anya.png"
}
margin: 0
extrude_borders: 2
inner_padding: 0
```

---

## Шаг 4: Регистрация в novel_ui.gui_script

1. Откройте файл: `main/gui/novel_ui.gui_script`
2. Найдите функцию `get_portrait_name` (около строки 306)
3. Добавьте новый персонаж:

```lua
local function get_portrait_name(character_name)
    if character_name == "Мила" then return "Мила" end
    if character_name == "Артём" then return "Артём" end
    if character_name == "Аня" then return "Аня" end  -- НОВЫЙ
    return nil
end
```

**Важно:** Имя должно совпадать с тем, что используется в Ink-тегах `# speaker:`.

---

## Шаг 5: Создание GUI-ноды для портрета

1. Откройте файл: `main/gui/novel_ui.gui` в Defold Editor
2. Найдите секцию с портретами (ноды `portrait_artem`, `portrait_mila`)
3. Создайте новую ноду:
   - **Type:** Box
   - **ID:** `portrait_anya` (или другое имя)
   - **Texture:** `characters/anya` (из атласа)
   - **Position:** примерно `(-200, 0, 0.4)` (за левым краем экрана)
   - **Size:** `(512, 512, 0)`
   - **Enabled:** false (по умолчанию скрыт)

4. Сохраните GUI

---

## Шаг 6: Регистрация ноды в gui_script

1. Откройте файл: `main/gui/novel_ui.gui_script`
2. Найдите функцию `init(self)` (около строки 140)
3. Найдите секцию где создается таблица `S.portraits`
4. Добавьте новый портрет:

```lua
S.portraits = {
    ["Артём"] = gui.get_node("portrait_artem"),
    ["Мила"]  = gui.get_node("portrait_mila"),
    ["Аня"]   = gui.get_node("portrait_anya"),  -- НОВЫЙ
}
```

---

## Шаг 7: Использование в Ink

В файле `chapter_01.ink` используйте тег `# speaker:`:

```ink
=== talk_with_anya
# bg:bg_office # speaker:Аня
Привет! Ты получил мое сообщение?

# speaker:mc
Да, только что прочитал.

# speaker:Аня
Отлично. Встретимся на крыше?
-> DONE
```

**Автоматика:**
- Когда `# speaker:Аня` → портрет Ани появляется слева с анимацией
- Когда `# speaker:mc` → портрет Ани скрывается, показывается портрет ГГ
- Когда `# speaker:none` → все портреты скрываются (нарратор)

---

## Специальные персонажи

### mc (главный герой)
```ink
# speaker:mc
```
Автоматически подставляется имя ГГ из `save_manager`:
- Если выбран мужской пол → "Артём" → портрет Артёма
- Если выбран женский пол → "Мила" → портрет Милы

### npc (второстепенный персонаж)
```ink
# speaker:npc
```
Автоматически подставляется имя НПС противоположного пола:
- Если ГГ мужчина → "Мила"
- Если ГГ женщина → "Артём"

### none (нарратор)
```ink
# speaker:none
```
Скрывает все портреты, показывает терминальную панель (если нужно).

## Анимация портретов

Портреты автоматически анимируются при появлении:
- **Slide-in** слева (от x=-200 до x=100)
- **Fade-in** (от alpha=0 до alpha=1)
- **Длительность:** 0.3 секунды
- **Easing:** EASING.OUTQUAD

Анимация настраивается в функции `show_portrait()` в `novel_ui.gui_script`.

---

## Позиционирование текста

Когда портрет показан, текст диалога автоматически сдвигается вправо:
- **Без портрета:** текст начинается с x=80
- **С портретом:** текст начинается с x=280 (освобождает место для портрета)

Это настраивается в функции `shift_text_for_portrait()`.

## Troubleshooting

**Портрет не отображается:**
- Проверьте что файл добавлен в `characters.atlas`
- Проверьте имя в `get_portrait_name()` (должно совпадать с `# speaker:`)
- Убедитесь что GUI-нода создана и зарегистрирована в `S.portraits`

**Портрет отображается неправильно:**
- Проверьте размер изображения (должен быть 512×512)
- Проверьте что фон прозрачный (RGBA, не RGB)
- Проверьте позицию ноды в GUI

**Анимация не работает:**
- Проверьте начальную позицию ноды (должна быть за левым краем: x=-200)
- Проверьте что нода enabled=false по умолчанию

**Текст накладывается на портрет:**
- Проверьте функцию `shift_text_for_portrait()`
- Убедитесь что константы `TEXT_X_PORTRAIT` и `TEXT_W_PORTRAIT` настроены правильно

## Примечания

- Портреты показываются только в dialogue-режиме (не в choice-режиме)
- При смене персонажа предыдущий портрет мгновенно скрывается
- Портреты автоматически скрываются в меню и на концовках
- Один персонаж = один портрет (нет вариаций эмоций пока)
