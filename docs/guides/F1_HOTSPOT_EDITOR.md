# F1 Hotspot Editor

`F1 Hotspot Editor` — встроенный дев-инструмент для настройки координат hotspot'ов и scene objects прямо во время игры.

## Где он подключён сейчас

- runtime-модуль: `main/scripts/hotspot_editor.lua`
- активный GUI bridge: `main/gui/components_v2/hotspots_v2.gui_script`

Это уже не legacy `novel_ui`, а текущий `v2`-stack.

## Когда он работает

- только когда активен `scene_controller`
- то есть внутри exploration-сцен, а не в обычном Ink-диалоге

## Управление

| Клавиша | Действие |
| --- | --- |
| `F1` | включить / выключить редактор |
| `Esc` | выйти из режима |
| `Tab` | следующий элемент |
| клик мышью / тап | выбрать hotspot |
| `← → ↑ ↓` | двигать элемент |
| `Shift + стрелки` | двигать быстрее |
| `[` / `]` | уменьшить / увеличить ширину |
| `;` / `'` | уменьшить / увеличить высоту |
| `P` | вывести текущие координаты в консоль Defold |

## Что он умеет редактировать

- hotspot'ы
- scene objects

Редактор циклически проходит по элементам сцены: сначала hotspot'ы, потом objects, потом снова hotspot'ы.

## Типичный workflow

1. Добавьте сцену или hotspot в `main/data/scenes/<location>.lua` (apartment / office / locations и т.п.)
2. Запустите игру
3. Войдите в нужную exploration-сцену
4. Нажмите `F1`
5. Подгоните положение / размер
6. Нажмите `P`
7. Скопируйте строки из консоли обратно в соответствующий location-файл

## Важно

- редактор меняет данные только в памяти
- `scenes.lua` на диск автоматически не записывается
- финальные значения всё равно нужно переносить руками в код

## Troubleshooting

### `F1` ничего не делает

- проверьте, что вы действительно в exploration-сцене
- проверьте, что активен current `v2` bootstrap

### Элементы не видно

- проверьте `visible_when`
- проверьте, что hotspot / object реально существует в `scenes.lua`

### Координаты печатаются, но не совпадают с ожиданием

- помните, что система координат — `1280x720`, origin снизу слева
