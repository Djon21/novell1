# F1 Hotspot Editor - Инструкция

## Что это?

**F1 Hotspot Editor** — встроенный инструмент для визуальной настройки координат hotspot'ов в point-and-click сценах. Используется только на этапе тестирования и разработки.

---

## Как использовать

### Шаг 1: Запуск редактора

1. Запустите игру в Defold (F5)
2. Перейдите в нужную point-and-click сцену
3. Нажмите **F1** на клавиатуре

**Результат:** Все hotspot'ы сцены станут видимыми (подсвечены рамками).

---

### Шаг 2: Навигация

**Tab** - переключение между hotspot'ами
- Выбранный hotspot подсвечивается ярче
- Переключение циклическое (после последнего → первый)

**Стрелки на клавиатуре** - перемещение выбранного hotspot'а
- ↑ - вверх
- ↓ - вниз
- ← - влево
- → - вправо

**P** - вывести координаты в консоль Defold
- Координаты выводятся в формате: `rect = { x = 100, y = 200, w = 150, h = 80 }`
- Смотрите консоль Defold (внизу редактора)

**F1** - выход из редактора
- Hotspot'ы снова становятся невидимыми
- Игра продолжается в обычном режиме

---

## Workflow

### Типичный процесс настройки hotspot'ов:

1. **Создайте hotspot в scenes.lua** с примерными координатами:
   ```lua
   {
       id = "new_hotspot",
       rect = { x = 100, y = 100, w = 200, h = 150 },
       label = "Новый объект",
       icon = "",
       action = { type = "goto_scene", scene = "other_room" },
   }
   ```

2. **Запустите игру** (F5) и перейдите в сцену

3. **Откройте редактор** (F1)

4. **Найдите нужный hotspot** (Tab)

5. **Настройте позицию** (стрелки на клавиатуре)

6. **Выведите координаты** (P)

7. **Скопируйте из консоли** в `scenes.lua`

8. **Перезапустите игру** для проверки

---

## Важные замечания

### ⚠️ Координаты НЕ сохраняются автоматически!

Редактор только **показывает** и **помогает настроить** hotspot'ы. Вы должны:
1. Нажать **P** для вывода координат
2. Скопировать их из консоли Defold
3. Вручную вставить в `main/scripts/scenes.lua`
4. Перезапустить игру

### Координатная система

- **Разрешение:** 960×640 пикселей
- **Origin:** левый-нижний угол (OpenGL style)
- **rect:** `{ x, y, w, h }` где:
  - `x, y` - левый-нижний угол прямоугольника
  - `w, h` - ширина и высота

### Только для тестирования

F1-редактор доступен только в **debug-сборке**. В релизной версии игры он отключен.

## Пример использования

### До настройки (scenes.lua):
```lua
kitchen = {
    bg = "bg_kitchen",
    hotspots = {
        {
            id = "coffee_maker",
            rect = { x = 100, y = 200, w = 150, h = 150 },  -- примерные координаты
            label = "Кофемашина",
            icon = string.char(0xEE, 0x95, 0x81),
            action = { type = "ink_knot", knot = "use_coffee_machine" },
        },
    },
}
```

### Процесс:
1. F5 - запуск игры
2. Переход на кухню
3. F1 - открыть редактор
4. Tab - выбрать coffee_maker
5. Стрелки - подвинуть на правильное место
6. P - вывести координаты

### Консоль Defold показывает:
```
[hotspot_editor] coffee_maker: rect = { x = 155, y = 250, w = 160, h = 155 }
```

### После настройки (scenes.lua):
```lua
kitchen = {
    bg = "bg_kitchen",
    hotspots = {
        {
            id = "coffee_maker",
            rect = { x = 155, y = 250, w = 160, h = 155 },  -- точные координаты
            label = "Кофемашина",
            icon = string.char(0xEE, 0x95, 0x81),
            action = { type = "ink_knot", knot = "use_coffee_machine" },
        },
    },
}
```

## Горячие клавиши (краткая справка)

| Клавиша | Действие |
|---------|----------|
| F1 | Вкл/Выкл редактор |
| Tab | Следующий hotspot |
| ↑↓←→ | Перемещение hotspot'а |
| P | Вывести координаты в консоль |

## Troubleshooting

**F1 не работает:**
- Убедитесь что вы в point-and-click сцене (не в ink-диалоге)
- Проверьте что это debug-сборка (не release)

**Hotspot'ы не видны после F1:**
- Проверьте что сцена загружена через scene_controller
- Убедитесь что в сцене есть hotspot'ы в scenes.lua

**Tab не переключает hotspot'ы:**
- Возможно в сцене только один hotspot
- Проверьте что hotspot'ы не скрыты через visible_when

**Координаты не выводятся при нажатии P:**
- Убедитесь что hotspot выбран (подсвечен)
- Проверьте консоль Defold (внизу редактора)

## Альтернативный способ

Если F1-редактор не работает или неудобен, можно настроить координаты вручную:

1. Откройте фон в графическом редакторе (Photoshop, GIMP)
2. Измерьте координаты нужной области
3. Конвертируйте из top-left в bottom-left:
   ```
   y_bottom_left = 640 - y_top_left - height
   ```
4. Вставьте координаты в scenes.lua
5. Тестируйте в игре

F1 Hotspot Editor — удобный инструмент для быстрой настройки hotspot'ов без необходимости перезапускать игру после каждого изменения координат. Используйте его на этапе разработки для точного позиционирования интерактивных зон.
