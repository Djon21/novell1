# Инструкция по добавлению новых фонов

## Шаг 1: Подготовка изображения

1. Создайте изображение **1920×1080 пикселей** (Full HD, 16:9)
2. Сохраните в формате **JPEG** (.jpg)
3. Оптимизируйте размер файла (~250-300 KB)
4. Назовите файл по шаблону: `bg_название.jpg`

## Шаг 2: Добавление файла в проект

1. Поместите файл в папку: `main/images/`
2. Пример: `main/images/bg_city_map.jpg`

## Шаг 3: Регистрация в атласе

1. Откройте файл: `main/images/backgrounds.atlas`
2. Добавьте новую запись **перед** строками `margin: 0`:

```
images {
  image: "/main/images/bg_название.jpg"
}
```

**Пример:**
```
images {
  image: "/main/images/bg_city_map.jpg"
}
```

## Шаг 4: Использование в игре

В файле `chapter_01.ink` используйте тег:
```
# bg:bg_название
```

**Пример:**
```
=== city_map_hub
# bg:bg_city_map # color:0.1,0.1,0.15 # speaker:none
Карта района. Маршруты проложены...
```

## Важно!

- Имя в атласе: `/main/images/bg_название.jpg`
- Имя в ink-теге: `bg:bg_название` (без расширения и пути)
- Defold автоматически масштабирует фон под игровое разрешение (960×640)
