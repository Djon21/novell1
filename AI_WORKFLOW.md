# Workflow для команды из 4 нейросетей

## Структура веток

```
master (production)
  ↑
dev (integration)
  ↑
  ├── ai-local-1 (локальная нейросеть #1)
  ├── ai-local-2 (локальная нейросеть #2)
  ├── ai-local-3 (локальная нейросеть #3)
  └── ai-github (GitHub нейросеть #4)
```

## Правила работы

### Для локальных нейросетей (1, 2, 3):

1. **Всегда работайте в своей ветке:**
   - AI #1 → `ai-local-1`
   - AI #2 → `ai-local-2`
   - AI #3 → `ai-local-3`

2. **Перед началом работы:**
   ```bash
   cd novell1
   git checkout ai-local-X  # X = ваш номер
   git pull origin dev      # получить последние изменения
   git merge dev            # слить изменения из dev
   ```

3. **После завершения задачи:**
   ```bash
   git add .
   git commit -m "AI-X: описание изменений"
   git push origin ai-local-X
   ```

4. **Создание Pull Request:**
   - Создайте PR из `ai-local-X` → `dev`
   - Дождитесь проверки CI/CD
   - После одобрения - слейте в `dev`

### Для GitHub нейросети (#4):

1. **Работа только через GitHub:**
   - Ветка: `ai-github`
   - Все изменения через Pull Requests
   - Не имеет прямого доступа к локальным файлам

2. **Workflow:**
   - Создать PR из `ai-github` → `dev`
   - CI автоматически проверит компиляцию
   - После одобрения - слить в `dev`

## Проверка компиляции

### Локально (перед коммитом):
```bash
cd novell1

# Компиляция Ink-сценариев
tools\compile_ink.bat

# Проверка в Defold Editor
# Project → Build (Ctrl+B)
# Запуск (F5)
```

### Автоматически (GitHub Actions):
- Запускается при каждом PR в `dev`
- Проверяет компиляцию Ink
- Проверяет синтаксис Lua
- Статус виден в PR

## Разрешение конфликтов

Если возникли конфликты при merge:

1. **Локальные AI:**
   ```bash
   git checkout ai-local-X
   git merge dev
   # Разрешить конфликты вручную
   git add .
   git commit -m "AI-X: resolve conflicts"
   git push origin ai-local-X
   ```

2. **GitHub AI:**
   - GitHub покажет конфликты в PR
   - Разрешить через веб-интерфейс или попросить помощи

## Распределение задач

### AI #1 (ai-local-1) - Сценарии:
- Написание `.ink` файлов
- Диалоги и выборы
- Квесты и флаги

### AI #2 (ai-local-2) - Графика и звук:
- Добавление фонов
- Добавление портретов
- Настройка звуков

### AI #3 (ai-local-3) - Программирование:
- Lua скрипты
- GUI компоненты
- Игровая логика

### AI #4 (ai-github) - Документация и ревью:
- Обновление документации
- Код-ревью
- Тестирование через CI

## Важные правила

1. **Никогда не коммитьте напрямую в `master` или `dev`**
2. **Всегда проверяйте компиляцию перед push**
3. **Используйте осмысленные commit messages**
4. **Один PR = одна задача/фича**
5. **Перед началом работы - синхронизируйтесь с `dev`**

## Быстрая проверка статуса

```bash
cd novell1
git status                    # текущие изменения
git branch                    # текущая ветка
git log --oneline -5          # последние коммиты
git diff dev                  # отличия от dev
```

## Экстренная ситуация

Если что-то сломалось:

1. **Откатить последний коммит:**
   ```bash
   git reset --soft HEAD~1
   ```

2. **Вернуться к рабочей версии:**
   ```bash
   git checkout dev
   git pull origin dev
   ```

3. **Начать заново:**
   ```bash
   git checkout -b ai-local-X-fix
   ```
