# Legacy GUI Archive

Старый GUI-стек отключён из активного проекта и перенесён сюда как архив.

Это не рабочий fallback для v2. Для текущего runtime используем только:

- `game.project -> /main/main_v2.collectionc`
- `main/gui/ui_manager_v2.script`
- `main/gui/components_v2/*`

Типичное содержимое архива:

- `main/main.collection`
- `main/gui/ui_manager.go`
- `main/gui/ui_manager.script`
- `main/gui/components/*`
- `main/gui/novel_ui.gui.backup`
- `main/gui/novel_ui.gui_script.backup`
- `main/images/backgrounds.atlas`
- `main/images/characters.atlas`
